# Agent Guidance

## Preserve familiar workflows

JoyVet Sales users prefer familiar, stable behavior. Treat existing sorting, ordering, labels, navigation, and defaults as compatibility contracts. Avoid changing these behaviors unless the user explicitly requests it or the change is required to fix a defect.

When a behavior must change, preserve the existing default where possible and make any new behavior opt-in. In particular, customer lists and customer pickers should remain alphabetically ordered by full name unless the user asks for a different order.
